OptiMind Privacy Policy

Effective date: August 31, 2026

OptiMind is a procurement and workflow management application. This policy explains how OptiMind handles information when a user connects a Gmail account.

Information We Access

With the user's permission, OptiMind accesses the Gmail account address and the message metadata needed to send notifications and apply the OptiMind label to relevant messages. This can include message IDs, senders, recipients, subjects, and Gmail label information.

OptiMind does not intentionally use Gmail access to read unrelated personal emails. Access is limited to the functionality described here.

How We Use Information

  • Send procurement and workflow notifications.
  • Locate relevant notification messages in Gmail.
  • Create or apply the OptiMind label to relevant messages.
  • Maintain and troubleshoot the application.

Storage and Security

OAuth tokens are stored on the application server and used only for the Gmail functionality authorized by the user. Access is restricted to authorized application administrators.

Data Sharing

OptiMind does not sell or rent personal information. Information is shared only with services required to operate the application, such as Google's Gmail API and the configured email delivery service.

Retention and Deletion

Users can revoke Gmail access from their Google Account security settings. Users can also contact us to request deletion of stored OAuth tokens and application-related personal information.

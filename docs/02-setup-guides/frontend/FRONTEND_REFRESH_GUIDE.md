# 🔄 前端更新指南

## 问题：看不到新的 UI

可能原因：
1. 浏览器缓存了旧版本
2. 代码没有重新编译

---

## 解决方案

### 方法 1：硬刷新浏览器（推荐）

**Windows:**
- `Ctrl + Shift + R` 或
- `Ctrl + F5`

**Mac:**
- `Cmd + Shift + R`

---

### 方法 2：清除缓存

1. 打开浏览器开发者工具（F12）
2. 右键点击刷新按钮
3. 选择"清空缓存并硬性重新加载"

---

### 方法 3：重启前端服务器

```bash
# 停止前端
# Ctrl + C

# 重新启动
cd client
npm start
```

---

## ✅ 确认新 UI 已加载

新 UI 应该显示：
- ✅ 圆角输入框（24px）
- ✅ 工具按钮在输入框内（📎 🖼️）
- ✅ 圆形发送按钮
- ✅ 白色背景 + 轻微阴影

---

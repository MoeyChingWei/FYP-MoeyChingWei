## 🐛 已知问题和边界情况

### ⚠️ 可能的问题：

1. **缩略图生成失败**
   - 某些图片格式可能不生成缩略图
   - 这不影响原图上传和显示

2. **AI 图片分析**
   - Task 8 未完成时，AI 不会分析图片内容
   - AI 只会说收到图片但不描述内容

3. **大文件上传时间**
   - 接近 10MB 的文件可能需要几秒上传
   - 应该显示加载状态

4. **并发上传**
   - 多个文件会逐个上传
   - 如果某个失败，其他仍继续

## 🔍 调试技巧

### 查看网络请求

打开浏览器开发者工具 → Network 标签页：

1. **上传请求：**
   ```
   POST /api/chatbot/upload-attachment
   Status: 200
   Response: {success: true, attachment: {...}}
   ```

2. **发送消息：**
   ```
   POST /api/chatbot/chat
   Body: {message: "...", attachmentData: [...]}
   ```

3. **查看附件：**
   ```
   GET /uploads/messages/{sessionId}/{filename}
   Status: 200
   ```

### 查看控制台

检查是否有错误：
```javascript
// 正常日志
✅ File uploaded: test.png (52.3 KB)
✅ Message sent with 2 attachments

// 错误日志
❌ Upload Error: File too large
❌ Failed to send message
```

### 查看数据库

使用 Prisma Studio：
```bash
cd backend
npm run prisma:studio
```

检查表：
- `chat_messages` - 应该有 metadata 或关联
- `message_attachments` - 应该有附件记录
